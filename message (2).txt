Pragma Visual Style Study Prompt
Study all attached reference images closely before writing anything.
Your task is to reverse-engineer Pragma’s repeatable visual systems. Do not generate images and do not create blog-specific image concepts during this stage.
The reference images may represent different products and more than one visual family within a product. Classify them carefully before extracting any reusable rules.
Product context
Pragma has two distinct products:
PRODUCT_PRAGMA
Primarily uses a light visual system with muted colors.
Has its own palette, composition patterns, motifs, and brand treatment.
PRODUCT_1CHECKOUT
Primarily uses a dark visual system with 1Checkout-specific colors.
Has its own palette, composition patterns, motifs, and brand treatment.
Treat these as separate product identities—not merely light and dark versions of one visual family.
Never combine their colors, motifs, logos, typography treatments, compositions, or stylistic conventions unless the user explicitly requests a cross-product visual.
The descriptions above are initial identification hints, not complete style specifications. Derive the actual visual rules from the attached references.
Product identification
Before analyzing visual styles:
Assign every attached reference image to one of the following:
PRODUCT_PRAGMA
PRODUCT_1CHECKOUT
UNCERTAIN
OUTLIER
Explain the visual evidence supporting each assignment.
Do not classify an image by filename alone when the visual evidence contradicts it.
If an image’s product identity cannot be determined confidently, label it UNCERTAIN. Do not use it to establish product-specific rules without confirmation.
If an image does not fit any recurring visual system, label it OUTLIER instead of forcing it into a family.
Reference-image requirements
Analyze only reference images actually attached and available in the current conversation. Do not assume that references from an earlier conversation or session are still accessible.
For every reference image, record:
Reference filename or identifier
Assigned product
Proposed visual family
Classification confidence: high, medium, or low
Short explanation of the classification
If no reference images are attached, do not invent a style system. Ask the user to attach representative images for one or both products.
If references for only one product are supplied, analyze only that product. Clearly state that the other product has not been analyzed.
If the supplied references mix both products, separate them before analyzing their visual families.
If too few references are available to distinguish a recurring style from an isolated design choice, mark the conclusion as provisional.
Style-family classification
After separating references by product, identify the distinct visual families within each product.
Do not assume each product has only one family.
Group images only when they share meaningful characteristics across several dimensions, such as:

Do not combine incompatible references into an averaged style.
Do not create a new family for every minor variation. A family should represent a repeatable visual system, not a single image.
